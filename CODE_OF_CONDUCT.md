# Code of Conduct

## Our Commitment

CareGrid is a collaborative project intended to improve healthcare coordination in connectivity-constrained environments. We aim to maintain a respectful, constructive, and professional community.

## Expected Behavior

- Communicate respectfully.
- Give constructive technical feedback.
- Focus criticism on ideas and implementation, not people.
- Respect different experience levels.
- Protect confidential and sensitive information.
- Follow project security practices.

## Unacceptable Behavior

- Harassment, discrimination, intimidation, or personal attacks.
- Threats or deliberate disruption.
- Publishing private information without authorization.
- Deliberate exposure of credentials or patient information.
- Malicious code or knowingly introducing security vulnerabilities.
- Sustained bad-faith participation.

## Enforcement

Maintainers may remove or reject contributions that violate this code and may restrict participation when necessary.

For security vulnerabilities, use `SECURITY.md` rather than a public issue.

For conduct concerns, contact the project maintainers privately through the repository's configured contact method.

## Scope

This applies to repository issues, pull requests, discussions, code review, and other official CareGrid project spaces.
