# Support

## Getting Help

Before asking for help:

1. Read `README.md`.
2. Read `DEVELOPMENT.md`.
3. Search existing GitHub issues.
4. Review the relevant architecture/API documentation.

## Bug Reports

For reproducible non-security bugs, include:

- Operating system.
- Component.
- Version/commit.
- Device/emulator.
- Network condition.
- Steps to reproduce.
- Expected behavior.
- Actual behavior.
- Relevant logs/screenshots.

Remove passwords, tokens, patient information, and other sensitive data.

## Feature Requests

Explain:

- The problem.
- Users/roles affected.
- Proposed behavior.
- Alternatives considered.
- Offline/connectivity implications.

## Security

Use `SECURITY.md` for vulnerabilities.

## Emergency / Clinical Use

CareGrid is software, not an emergency medical service. In real medical emergencies, follow applicable local emergency and clinical procedures.
